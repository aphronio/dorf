# Security policy

## Supported versions

Dorf is currently an alpha project. Security fixes are provided for the latest released version.

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue or pull request. Use
[GitHub's private vulnerability reporting](https://github.com/aphronio/dorf/security/advisories/new)
to contact the maintainer privately.

Include the affected version or commit, the impact, reproduction steps, and any suggested
mitigation. You should receive an acknowledgement within seven days. Please allow time for a fix
and coordinated release before publicly disclosing the report.
