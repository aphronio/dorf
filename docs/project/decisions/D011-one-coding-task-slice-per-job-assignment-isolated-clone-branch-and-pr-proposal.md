# D011: One coding task slice per Job, Assignment, isolated clone, branch, and PR proposal

- **Applicability:** partial
- **Areas:** workflows, sandboxes, github
- **Read when:** Changing the cardinality between a coding Job, clone, branch, and proposal.
- **Decision history:** Retained pre-consolidation decision.
- **Decision:** One coding task slice per Job, Assignment, isolated clone, branch, and PR proposal.
- **Why:** Revision retains those identities; merge, rejection, or abandonment is workflow-terminal.
- **Reconsider when:** A concrete workflow needs different cardinality with equally clear acceptance semantics.
