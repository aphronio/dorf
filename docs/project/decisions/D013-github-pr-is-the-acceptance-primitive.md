# D013: GitHub PR is the acceptance primitive

- **Applicability:** current
- **Areas:** workflows, github
- **Read when:** Changing how a coding workflow records acceptance, rejection, or review.
- **Decision history:** Retained pre-consolidation decision.
- **Decision:** GitHub PR is the acceptance primitive.
- **Why:** Git and GitHub already provide durable diffs, review, merge, and rejection.
- **Reconsider when:** A non-GitHub coding workflow becomes a real requirement.
