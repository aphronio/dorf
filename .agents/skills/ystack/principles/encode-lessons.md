# Encode lessons

A correction given twice is a missing structure. Compounding beats repeating.

- When the same instruction repeats, encode it: first as a check, lint, script, type or generator a
  machine enforces; only if that is impossible, as one line in the owning AGENTS.md or a ystack
  principle.
- Put mechanically decidable rules in the repo's task runner or checks. Keep judgment in prose. See
  the [hygiene playbook](../playbooks/hygiene.md).
- One unusual task is not a rule. Wait for a second occurrence or explicit owner direction.
- Prefer deleting a stale rule to adding a new one.
- Propose ystack edits through the `ystack-learn` skill so the owner approves every change.

Test: Will the next agent make this mistake again, and what stops it without anyone remembering?
